# Syed Zamin Ali — Personal Portfolio

A responsive personal portfolio website built for Lab Task 1.

## Sections

- **About Me** — Bio, education, and soft skills
- **Project Showcase** — Destino App, Cash Flow Minimizer, Face Recognition System
- **Resume** — Education, technical skills, CV download
- **Contact** — Email, phone, LinkedIn, GitHub

## View Locally

Open `index.html` in your browser, or run a local server:

```bash
npx serve .
```

## Deploy

Upload the folder to [GitHub Pages](https://pages.github.com/), [Netlify](https://netlify.com), or [Vercel](https://vercel.com) for a live URL.
